# Glossary

- **AI-DLC (AI-Driven Development Lifecycle):** A methodology designed to heavily integrate AI into the software development process from inception to operations, emphasizing structured collaboration and explicit planning.
- **Riverpod:** A reactive caching and state management framework for Flutter, heavily used in this app.
- **Supabase:** The backend-as-a-service platform used for authentication, storing user profiles, and remote data synchronization.
- **FCM (Firebase Cloud Messaging):** A cross-platform messaging solution that lets you reliably send messages and notifications.
- **OCG IELTS:** The name of the Flutter application designed for IELTS preparation and study material delivery.
